# Smart Eye Monitoring System 👁️

## Features
• Developed a real-time eye monitoring system using Python, OpenCV, and MediaPipe, achieving 90%+ accuracy in eye state detection under normal lighting conditions.
• Implemented facial landmark-based eye aspect ratio technique, enabling detection of eye closure within < 0.5
seconds latency.
• Integrated an alert mechanism that triggers an alarm when eyes remain closed for more than 2 seconds, reducing
unnoticed drowsiness/blinking events by 80%.
• Designed a background timer system that provides break reminders every 30 minutes, improving user productivity and reducing eye strain.
• Built an interactive GUI using Tkinter with Start/Stop controls, ensuring smooth user interaction with realtime performance and minimal CPU usage.


## Tech Used
- Python
- OpenCV
- MediaPipe
- Tkinter
